# About & credits

## What this wiki is

This wiki is the central documentation source for
[zoompilot](https://zoompilot.ai), a Mazda-optimized fork of sunnypilot.
It is maintained as markdown in the open: the GitHub icon in the header
opens the wiki repository, and every push to its main branch deploys
the site.

## Standing on the shoulders of

zoompilot stands on sunnypilot, which stands on
[openpilot](https://comma.ai) by comma.ai. Nearly everything here rides on
their work.

- [openpilot](https://github.com/commaai/openpilot) — the open source
  driver assistance system by comma.ai.
- [sunnypilot](https://github.com/sunnypilot/sunnypilot) — the fork
  zoompilot builds on, by sunnyhaibin and the sunnypilot community.
  [Their documentation](https://github.com/sunnypilot/user-docs) (MIT)
  provided the structure and some adapted content for this wiki.
